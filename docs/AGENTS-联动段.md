## 资本市场联动（知识库 × 通达信）

分析个股 / 板块 / 大盘时，按 `market-research` 技能走完整流程：先 `kb_find` / `kb_search` 查方法论 → 再用 `tdx_*` 取实时数据 → 检查前提条件 → 输出分开标注「数据事实 / 方法论判断 / 出处（笔记 + offset）」。

- 新增检索工具：`kb_find`（官方分词检索，换一种说法也能找到）、`kb_space_list` / `kb_space_browse` / `kb_space_search`（个人知识库文件）
- 通达信工具返回空数据就直说没取到，**绝不编造行情数字或指标**
- 「默认不查知识库」的规则不变：用户没让分析市场就不查
- 引用知识库必须说清出自哪篇笔记和位置（offset），区分原文与我的推断
